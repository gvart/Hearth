## One command, and the device is in

Start a hub, click **Add device** in its web UI and paste the command it gives you on a Raspberry Pi,
a NAS or a laptop:

```sh
curl -fsSL https://raw.githubusercontent.com/gvart/Hearth/v0.0.1-rc.9/deploy/install.sh | HEARTH_TOKEN=hearth2.… sh -s -- --version v0.0.1-rc.9
```

The agent installs as a service, enrolls over mTLS with a single-use token and dials out to the hub:
no inbound ports on the device. It shows up online with its facts within seconds, and CI fails any
change that makes it take longer than ten. [Get started](/getting-started/).

## What it does

<CardGrid>
	<Card title="See every device" icon="laptop">
		Facts, metrics, logs and a web terminal for every agent. **Scan my network** finds the other hosts
		on your LAN (ARP, mDNS, DHCP leases), tells a printer from a computer, and lets you add an agent
		to one or adopt it as it is. [Discovery](/discovery/).
	</Card>
	<Card title="Automations that act" icon="setting">
		YAML, kept in git if you like: a device goes offline, a check fails or a metric runs hot, and
		Hearth restarts the service, calls a webhook or notifies you. [Automations](/automations/).
	</Card>
	<Card title="Runbooks" icon="list-format">
		Multi-step procedures with checks, prompts, retry and rollback, started from the UI or the CLI.
		[Runbooks](/runbooks/).
	</Card>
	<Card title="Adopt, don't replace" icon="puzzle">
		Plugs into the Kubernetes, Talos, Prometheus, Pi-hole and Docker you already run. Nothing to
		migrate. [Kubernetes](/kubernetes/), [Prometheus](/prometheus/).
	</Card>
	<Card title="Deny by default" icon="approve-check">
		Every action from the UI, the CLI, an automation or an AI assistant passes one policy engine and
		lands in an audit log, and each device sets its own ceiling. [Security model](/security/).
	</Card>
	<Card title="Agent-native" icon="comment">
		A built-in MCP server lets Claude Code and other assistants see and operate the lab, under the
		same policy as everyone else. [MCP](/mcp/).
	</Card>
	<Card title="A cluster with no leader" icon="random">
		Add hubs and they form a leaderless cluster: agents move to another hub within seconds when one
		dies, and both sides of a network split keep working. [Cluster mode](/cluster/).
	</Card>
	<Card title="Small on the edge" icon="rocket">
		Hub and agent are one Go binary. The agent is built to idle under 25 MB of memory and near-zero
		CPU; the hub keeps its state in SQLite. [Concepts](/concepts/).
	</Card>
</CardGrid>

Hearth is pre-alpha and built in public: releases are `v0.0.1-rc.N` pre-releases for now. How it fits
next to Beszel, Komodo, NetAlertX and Homepage: [Hearth and other tools](/comparison/).
