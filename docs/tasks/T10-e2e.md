# T10 — End-to-end test of the headline demo

**Branch:** `t10-e2e` · **Depends on:** T5–T9

## Goal
CI proves the v0 promise: a new device shows up in under 10 seconds.

## Scope
- `test/e2e/compose.yaml`: one hub container, two agent containers built from the current commit.
- Go test (`//go:build e2e`) that: starts the stack; logs in; creates a token via API; runs `join` in each
  agent container; asserts both devices are `online` via the API within 10 s of `join`; stops one agent;
  asserts it turns `offline` within 40 s; restarts the hub; asserts both reconnect.
- `task e2e` runs it locally; CI job runs it on every PR to `main`.
- On failure, dump hub and agent logs as CI artifacts.

## Done when
- The e2e job is green and takes < 3 min in CI.
- The 10 s assertion is a named constant referenced from the README demo claim.
